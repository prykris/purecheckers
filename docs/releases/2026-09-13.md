# Board and room release — 13 September 2026

This release transfers the approved board prototype into the shared live-game and replay layout, and consolidates player headers, profile actions, room invitations and readiness. The app keeps its existing theme variables and authoritative server protocol. See the [board contract](../board-table.md) and [component reuse audit](../component-reuse-audit.md) for scope and remaining work.

## Rollout

Deploy `master` to the existing Railway web and puzzle-publisher services. Keep one web replica alongside PostgreSQL in `us-west2`. No schema migration or database reset is added. Startup still runs migration deployment, idempotent seeding and durable session recovery before serving requests. Deploy client and server together; existing browser tabs should reload for the new interface.

Room invitations add an optional `invites` array to the existing room JSON state. Older releases can discard this field when normalizing room state: pending room invitations must expire or be cleared before rolling back to that code. Do not change the database, region, ownership fencing or publisher schedule during a UI rollback.

## Daily puzzles

The separate publisher runs `node scripts/maintain-puzzles.js` at 02:00 UTC every day, with restart policy NEVER. It maintains today's puzzle plus 30 future dates, and checks seven upcoming puzzles again. The September 13 scheduled run committed one new puzzle and reported 31 consecutive available dates through October 13, no missing dates and no protected failures. An inconclusive deeper search kept its previously verified puzzle. The release must preserve this service and verify its updated deployment and public daily-puzzle endpoint.
